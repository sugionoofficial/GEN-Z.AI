Kredensial Opus

Khusus admin dan owner. Tambahkan akun sebanyak yang diperlukan. Token dienkripsi di server dan tidak ditampilkan kembali. Isi auth token atau API key; refresh token dan client ID opsional.

Kredensial lama di Cloudflare tetap digunakan sebagai cadangan. Untuk memindahkannya, masukkan setiap akun di sini, uji, lalu hapus secret lama secara manual.
