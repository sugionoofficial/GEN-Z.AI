Provider pembuatan gambar

Pilihan ini berlaku untuk pembuatan gambar manual dan autopost semua user.

Model yang mendukung pembuatan image karakter; persentase tier tersedia ditampilkan di samping nama model. Caption foto karakter tetap memakai qwen3-vl-plus.
QwenCloud tidak membuka API sisa kuota, jadi persentase dihitung dari ledger pemakaian aplikasi terhadap batas tier yang Anda isi. Status otomatis berubah menjadi "Tier habis" bila QwenCloud menolak dengan error kuota (429 / AllocationQuota.FreeTierOnly).
Khusus mode Kata-kata Mutiara + Musik Auto-Play otomatis memakai latar kosong hitam polos (#000000) sehingga 0 kuota model gambar terpakai, sementara kalimat mutiara dirangkai oleh model LLM QwenCloud pilihan di atas.
Setiap model LLM QwenCloud umumnya memiliki free quota besar (~1.000.000 token ≈ ribuan kalimat kata mutiara). Persentase sisa dihitung terhadap batas request yang Anda atur dan otomatis ditandai "Tier habis" jika model LLM tersebut menolak dengan error kuota (HTTP 429).
