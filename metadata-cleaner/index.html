GEN-Z.AI menggunakan dua lapisan pemeriksaan: analisis metadata lokal dan visual AI detection melalui Sightengine untuk image. Indikator metadata dapat membantu menemukan informasi yang berkaitan dengan proses atau aplikasi pembuat media, sedangkan Sightengine menganalisis karakteristik visual image.

Hasil AI detection merupakan skor atau confidence berdasarkan analisis sistem dan bukan bukti absolut mengenai asal-usul suatu media. Tidak adanya indikator metadata atau rendahnya skor AI detection tidak dapat menjamin bahwa media bukan dibuat atau dimodifikasi menggunakan AI.
